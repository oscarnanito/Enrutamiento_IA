# Enrutamiento_IA
## Este es un sistema organizado de algunas estaciones de servio de transporte publico de la ciudad de bogotá.

## El proyecto implementa conocimientos básicos de Python y algo de inteligencia artificial como busquedas y enrutamiento

## El objetivo es encontrar una ruta optima para llegar linealmente de un origen a otro 

## Tecnologías utilizadas
- Python
- Algoritmo A*
- Heurística

## Base de conocimiento
Se utiliza un grafo donde cada estación está conectada con otras mediante un costo.

## Algoritmo
Se implementa el algoritmo A* que combina:
- Costo real (g)
- Heurística (h)

## El programa presenta al usuario una lista de estaciones de tm y el usuario tendra que elegir origen y destino, para efectos prácticos se puso que el salto o paso por cada estacion tedra un cobro de 3550 pesos colombianos 

# Es un programa basico para la implementacion de nodos y busqueda, así como tambien algorimo a* y heuristica que es algo fundamental en iA
